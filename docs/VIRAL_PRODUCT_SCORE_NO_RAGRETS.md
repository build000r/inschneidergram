## Product Read

Inschneidergram is an API-first Instagram creator outreach control plane for a
managed Graphed pilot. The local product is strong because it does not pretend a
fragile browser script is enough: it has campaign intake, creator provenance,
approval gates, sender limits, manual/provider execution contracts, webhooks,
operator dashboard state, and proof packs.

The viral loop should not claim live Instagram delivery until the external
pilot inputs exist. The shareable object should be a bounty/evaluator proof
receipt: what the control plane can prove locally, what remains external, and
how a real pilot will become a proof pack once the operator supplies creator
list, approved copy, warmed sender access, launch authorization, and callback.

## Dueling Ideas Result

1. Add more automation around live Instagram sends.
2. Build a prettier dashboard first.
3. Package a bounty proof receipt and operator-input handoff.

Winner: bounty proof receipt and operator-input handoff.

More live-send automation risks crossing the compliance boundary that the repo
has already documented. A dashboard is useful later, but the immediate viral
and evaluator win is a small proof artifact that says: this control plane is
ready, this is what it proves locally, and these exact external inputs unlock
the real pilot proof.

## Execution Beads

The follow-up beads created from this plan should deliver:

- A compact local bounty proof receipt summarizing `proof:bounty-local`,
  intake validation, provider bridge rehearsal, service smoke, and proof-pack
  surfaces without requiring Instagram credentials.
- A live-pilot operator handoff receipt naming the four external inputs, stop
  conditions, evidence fields, and where real outcomes enter the manual-event
  queue.
- A trust-boundary explainer that keeps manual managed delivery, sender risk,
  callback security, and no-fake-live-evidence rules visible.
- A launch/evaluator packet that waits for those receipts before updating
  public copy or bounty submission material.

## Retro Check

This plan avoids the biggest likely regret: claiming live outreach readiness
from fixtures or adding gray-market automation. It turns the existing proof
pipeline into the shareable product while preserving the external pilot blocker
as a first-class truth.
